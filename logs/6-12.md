# snk-wallet-kit v0.2.0 发布记录

发布日期：2026-06-12

## 发布摘要

本次版本新增标准 EVM 自定义链支持，允许宿主应用直接传入兼容
`viem Chain` 的链配置，从而支持 Anvil、localhost、私链和其他 EVM
网络。同时修复 EVM 钱包连接残留问题，并完善 React / Next.js demo
中的多链切换、RPC 配置和余额同步展示。

本次升级保持现有预置链配置方式兼容：

```ts
chains: ["mainnet", "sepolia"]
```

## SDK 修改

### 自定义 EVM Chain

- 新增 `PresetEvmChain`、`EvmChainLike`、`EvmChainInput` 类型。
- `evm.chains` 从仅支持字符串，扩展为支持预置链名或标准链对象。
- 保留 `"mainnet"`、`"sepolia"` 预置链快捷写法。
- `createWalletKitEvmConfig` 现在可以解析并透传 Anvil、localhost、
  私链及其他自定义 EVM Chain。

示例：

```ts
const anvil = {
  id: 31337,
  name: "Anvil",
  nativeCurrency: {
    name: "Ether",
    symbol: "ETH",
    decimals: 18,
  },
  rpcUrls: {
    default: {
      http: ["http://127.0.0.1:8545"],
    },
  },
} as const;

const config = {
  evm: {
    chains: ["mainnet", "sepolia", anvil],
  },
};
```

### EVM 连接状态修复

- 连接新 EVM 钱包前清理 wagmi 中遗留的连接。
- 重新连接相同 connector 时清理旧连接状态。
- 断开钱包时清理全部活跃 EVM connections，避免残留连接导致地址、
  chainId 或钱包状态不一致。

## Demo 修改

### React / Next.js 多链配置

- 新增 Mainnet、Sepolia、Anvil 切链操作。
- 支持通过环境变量配置各链 RPC：

| 网络 | Next.js | React / Vite |
| --- | --- | --- |
| Mainnet | `NEXT_PUBLIC_MAINNET_RPC_URL` | `VITE_MAINNET_RPC_URL` |
| Sepolia | `NEXT_PUBLIC_SEPOLIA_RPC_URL` | `VITE_SEPOLIA_RPC_URL` |
| Anvil | `NEXT_PUBLIC_ANVIL_URL` | `VITE_ANVIL_URL` |

- 增加 `.env.example`，并允许 Next.js demo 提交该示例文件。
- Mainnet 和 Sepolia 默认使用已验证可访问的 PublicNode RPC。

### 余额展示修复

- 余额查询仅在 kit session 与 wagmi connection 的钱包地址和 chainId
  完全一致后执行。
- 切链同步期间显示 `Syncing wallet state...`。
- RPC 查询期间显示 `Refreshing...`，查询失败时显示明确错误。
- 禁用离线余额 query 缓存，避免切回旧网络时短暂展示过期余额。

### 调试能力

- 签名消息附带当前 EVM chainId，方便确认签名网络。
- 状态面板同时展示 kit session、wagmi address、wagmi status、chainId
  和当前余额。
